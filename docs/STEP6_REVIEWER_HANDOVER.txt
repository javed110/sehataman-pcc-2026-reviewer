FRESH INTERACTIVE REVIEW ON WINDOWS
Extract the ZIP to a short local path and open PowerShell in its SehatAman_PCC2026
folder. Python 3.12+ and installation of requirements.txt are prerequisites on a
new machine. The prepared laptop already has the runtime and dependencies.

For a new machine, without changing PowerShell execution policy:
  py -3.12 -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  .\.venv\Scripts\python.exe manage.py --home .local-reviewer serve --port 8788

On the prepared laptop, use this existing runtime instead of creating an environment:
  & 'C:\Users\HP\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' manage.py --home .local-reviewer serve --port 8788

Keep that server terminal open. In a second terminal in the same project folder,
use the SAME Python and home to display credentials:
  .\.venv\Scripts\python.exe manage.py --home .local-reviewer accounts
or, on the prepared laptop:
  & 'C:\Users\HP\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' manage.py --home .local-reviewer accounts

Open http://127.0.0.1:8788/ and http://127.0.0.1:8788/reviewer locally.
These addresses are run-locally instructions for this computer, not remote links
to an externally accessible demonstration.
Never paste credentials or second-factor codes into a submission or recording.
Codes rotate every 30 seconds; a successfully accepted code cannot be reused.
If needed, run accounts again after the next code interval. Use accounts with
--home .local-reviewer for this route: Show-DemoAccounts.cmd uses the default
.local home, whose credentials are different. A previously used review home
retains its state. For another clean run choose a new empty home name, using it
consistently for serve, accounts and fixture commands. No reset is necessary.
If port 8788 is busy, choose another unused loopback port and use it in the URLs.
